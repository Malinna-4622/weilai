## 🚀 免费部署指南（全程10分钟）

### 第一步：注册 GitHub

1. 打开 [github.com](https://github.com) 
2. 点击 **Sign up**，输入邮箱、密码、用户名
3. 验证邮箱 → 完成注册（免费，无需绑卡）

### 第二步：上传代码到 GitHub

**方法一（推荐 - 用网页直接上传）：**
1. 登录 GitHub，点击右上角 **+ → New repository**
2. Repository name 输入 `weilai`
3. 选择 **Public**（公开，免费托管必需）
4. 点击 **Create repository**
5. 在新页面点击 **uploading an existing file**
6. 将电脑上 `/未来/` 文件夹里的所有文件拖进去（包括子文件夹）
7. 点击 **Commit changes**

**方法二（用命令行）：**
```bash
# 如果你会 Git 的话
git init
git add .
git commit -m "🌱 初始化未来"
git remote add origin https://github.com/你的用户名/weilai.git
git push -u origin main
```

### 第三步：开启 GitHub Pages（免费托管前端）

1. 进入你的仓库 `你的用户名/weilai`
2. 点击 **Settings** → 左侧 **Pages**
3. Source 选择 **Deploy from a branch**
4. Branch 选择 **main**，文件夹选 **/(root)**
5. 点击 **Save**
6. 等1-2分钟，页面顶部会出现：
   > 🌐 Your site is live at `https://你的用户名.github.io/weilai/`

**这就是你的「未来」主页地址！用手机浏览器打开就能用。**

### 第四步：开启 Actions（自动巡检）

1. 进入仓库，点击 **Actions** 标签
2. 点击 **"I understand my workflows, go ahead and enable them"**
3. 左侧点击 **🌱 未来 · 每日自动巡检**
4. 右侧点击 **Enable workflow**

✅ 完成！明天早上8点，系统会自动巡检4个官网并更新公告数据。

你也可以随时手动触发巡检：在 Actions 页面点击 **Run workflow → Run workflow**。

### 第五步：添加到手机桌面（PWA）

**iPhone（Safari）：**
1. 打开 `https://你的用户名.github.io/weilai/`
2. 点击底部中间的 **分享按钮**（方形+箭头）
3. 向下滑，点击 **添加到主屏幕**
4. 点击右上角 **添加**
5. 桌面上出现「未来」图标，像APP一样打开

**安卓（Chrome）：**
1. 打开 `https://你的用户名.github.io/weilai/`
2. 点击右上角 **三个点** → **添加到主屏幕**
3. 点击 **添加**

## 📖 日常使用说明

### 每天看一眼
打开手机桌面上的「未来」→ Tab1首页：
- 顶栏显示巡检状态（绿色=正常）
- 数字统计：新公告/待报名/即将截止
- ★ 最值得你看的公告排第一
- 点击卡片展开完整内容

### 搜索历史公告
切换到 Tab2 台账：
- 搜索框输入 `城投`、`城联社`、`中小企业` 等
- 按单位分组展示，点击单位展开
- 每条公告显示报名时间、倒计时、竞争度

### 学面试
切换到 Tab3 备考 → 点击「面试」子标签：
- 五阶段从零入门到实战
- 点击展开每个阶段详情
- 按顺序学习效果更佳

### 追踪人生进度
Tab3 → 「时间轴」子标签：
- 每个阶段有具体任务清单
- 完成一项勾一项，自动保存进度
- ✅进度条可视化

### 修改关键词/监控网址
点击顶栏 ⚙️ 齿轮图标：
- 增删监控关键词
- 增删排除关键词
- 增删监控网址
- 修改个人资料（专业、性别等）
